# SpyKey Central

SpyKey Central is a dark, intelligence-inspired knowledge platform for AI workflows, digital intelligence, research, cybersecurity awareness, and knowledge discovery.

## Stack

- React and TypeScript
- Vite and Tailwind CSS v4
- React Router
- shadcn/ui-style components
- Cloudflare Workers and Hono

## Development

```bash
npm install
npm run dev
```

## Build and deploy

```bash
npm run build
npm run deploy
```

The React application lives in `src/react-app`, with reusable components, layouts, pages, hooks, data, and types organized under that directory. The Hono Worker remains in `src/worker`.

The production site is available at [vitereact-spykey.biancadelaze.workers.dev](https://vitereact-spykey.biancadelaze.workers.dev/).
